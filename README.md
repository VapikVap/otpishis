# Отпишись.

**Бесплатный открытый справочник: как отменить подписку, остановить автосписания и вернуть деньги.**

Яндекс Плюс, СберПрайм, Кинопоиск, Okko, Иви, Wink, App Store, Google Play, платные подписки у мобильных операторов, банковские «Pro» и «Смарт» — у каждого кнопка отмены спрятана по-своему. Здесь собраны пошаговые инструкции в одном месте.

👉 **Сайт:** https://vapikvap.github.io/otpishis/

## Что есть

- 🔍 **Каталог сервисов** с поиском: шаги отмены, официальные ссылки, подводные камни.
- 💸 **«Уже списали»:** что делать по порядку. Поддержка, претензия, оспаривание в банке, Роспотребнадзор.
- 📝 **Генератор претензии:** заполняете пять полей и получаете готовый текст со ссылками на закон. Всё считается в браузере, данные никуда не отправляются.

Без регистрации, рекламы, трекеров и платных функций.

## Помочь проекту

Самое ценное — **актуальные инструкции**. Интерфейсы меняются постоянно, и один человек за всеми не уследит.

- Шаги не совпадают? → [Сообщить об ошибке](../../issues/new?template=fix.yml)
- Нет нужного сервиса? → [Предложить сервис](../../issues/new?template=add.yml)
- Умеете в Git? → отредактируйте [`data/services.json`](data/services.json) и пришлите pull request. Подробнее в [CONTRIBUTING.md](CONTRIBUTING.md).

## Запустить у себя

Это обычный статический сайт без сборки:

```bash
python -m http.server 8000
```

Затем откройте http://localhost:8000.

## Дисклеймер

Это памятка, а не юридическая консультация. Инструкции собраны сообществом и могут устареть. Перед действием сверяйтесь с официальной справкой сервиса.
