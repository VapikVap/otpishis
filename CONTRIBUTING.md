# Как добавить или поправить сервис

Все инструкции лежат в одном файле: [`data/services.json`](data/services.json).

## Формат записи

```json
{
  "id": "okko",
  "name": "Okko",
  "category": "video",
  "aliases": ["окко"],
  "steps": [
    "Войдите на okko.tv тем же способом, которым оформляли подписку.",
    "Профиль → «Подписки» → отключите автопродление."
  ],
  "notes": "Подводные камни, если есть.",
  "links": [{"title": "Справка", "url": "https://..."}],
  "checked": "2026-11-02"
}
```

| Поле | Что писать |
|---|---|
| `id` | латиница, цифры и дефис, уникальный |
| `category` | один из ключей `categories` в начале файла |
| `aliases` | как люди ищут: транслит, сленг, название компании |
| `steps` | короткие шаги, по одному действию в каждом |
| `links` | только официальные страницы сервиса |
| `checked` | дата, когда **вы сами** прошли эти шаги, или `null` |

## Правила

- Не добавляйте реферальные ссылки и рекламу.
- Не выдумывайте шаги. Если не уверены — оставьте `checked: null` и напишите об этом в PR.
- Перед отправкой проверьте файл: `python tools/validate.py`
